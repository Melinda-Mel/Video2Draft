# WorkBuddy 工作手册（Playbook）

> 把「一个 AI 助理 + 一堆本地脚本 + 一套协作规矩」是怎么跑起来的，完整记录下来。
> 覆盖范围：2026-08-26 ~ 2026-09-20 的全部任务窗口，以及助理对话窗口里的协作约定。
> 状态：**已公开发布**（仓库 `Video2Draft`）。发布前的检查记录见 [docs/06-发布前检查.md](06-发布前检查.md)
> 与 [docs/08-发布清单与汇总.md](08-发布清单与汇总.md)。
>
> 运行环境口径（全仓库一致）：**macOS 已实测**；**Windows 代码已适配、端到端待实机验收**；Linux 未实测。

## 这是什么

一套可跨平台（macOS / Windows / Linux）的自动化工作流，核心是三件事：

1. **链接 → 一键成稿**：把视频号 / 抖音 / 小红书 / B站 / YouTube / X 的视频转成
   「关键要点 + 完整文案」，出成长图推送到微信，并归档到本地资料库。
2. **一批自己攒的 CLI 小工具**：出图、推送、提醒音、审批记录转规则、跨窗口检索等。
3. **一套协作纪律**：助理只做调度与汇报，重任务独立执行；失败两次就止损；
   先交付再补文档；聊天里只发图不发大段文字。

## 快速开始

跨平台入口（推荐，macOS / Windows / Linux 同一套命令）：

```bash
pip install -r requirements.txt          # 或先跑 bash install.sh / install.ps1 做环境检查
python3 tools/video2draft.py "<视频链接>"   # 产出 <标题>.md + <标题>.png + <标题>.json
python3 tools/video2draft.py --doctor      # 环境自检
```

前置条件（跨平台版）：

- Python 3.10+、ffmpeg；（出图另需 Chrome，缺了只影响出图）
- 输出目录默认 `~/Video2Draft`，用 `YJCG_OUTPUT_DIR` 可改
- 视频号是**可选适配器**：需自建第三方服务并设 `YJCG_SPH_ENDPOINT`，不装不影响其它五个平台

Legacy 链路（macOS 本机，保留不替换）：

```bash
python3 tools/make_card.py "<视频链接>"            # 依赖本机解析服务 / Node / wx-send
python3 tools/make_card.py "<视频链接>" --no-push
```

## 限制说明

用之前先确认这两条，不然很容易以为它坏了：

- **链接形态：目前只验证过一种。** 只跑通手机端「转发 → 复制链接」拿到的那种链接。
  桌面端复制、分享卡片、平台短链二次包装等形态**均未验证**，不保证可用。
  （已知的坑：链接一旦被二次包装或带参数，解析会失败。）
- **前置条件：助理侧必须在「管理 / 设置」里接入微信渠道。**
  「你发链接进来」和「图推回你微信」两个方向都靠它；没有这一步，只能手动跑命令、
  自己去输出目录拿文件，等于整套东西少了一半。

## 核心设计取舍

- **本地转写、云上整理**：音频不出本机（mlx-whisper 本地跑），
  只有转写后的文字发给大模型做结构化，成本与隐私都可控。
- **确定性纠错优先于模型纠错**：专有名词靠一张可维护的替换表纠正，不依赖模型「聪明」。
- **一条命令端到端**：慢的从来不是程序，而是「每完成一步都要重新思考一轮」。
- **不做低收益优化**：只省 1 秒但要背后台进程维护成本的方案，坚决砍掉。
