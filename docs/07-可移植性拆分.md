# 07 · 可移植性拆分（给别人用要怎么改）

> 目标：别人 clone 下来就能在自己的 Codex / Claude Code 里用。
> 结论先说：**网络那部分不是问题，真正要拆的是「视频号」和「推送到我微信」这两块。**

## 一、先回答「VPN 会不会影响别人」

不会。现状里 VPN 只是**你这台机器的出网方式**，不是流水线的一部分。展开讲：

| 网络相关的东西 | 别人需要吗 | 说明 |
|---|---|---|
| 本地 HTTP 代理（MITM） | **只有视频号需要** | 视频号靠代理抓微信客户端的流量，其它平台完全不碰它 |
| 代理内核里的 CDN 直连规则 | **只在「用户自己也开着规则代理」时才需要** | 规则本身是通用的（任何 Clash 系内核都认），不是某产品专有 |
| 隧道 / VPN 本体 | **不需要** | 境外平台才需要出网能力，谁都可以用自己的方式 |
| 系统代理设置 | 只有视频号需要，且是 macOS 专有命令 | Windows / Linux 写法不同，要做成分支或手动说明 |

**关键判断**：国内平台（B站 / 抖音 / 小红书 / 视频号）本来就不该走隧道，
你之所以踩到「VPN 一开就抓不到」，是因为代理内核把你 CDN 的流量也带走了 ——
这属于**配置问题**，不是架构依赖。别人只要不装规则代理，或装了但把 CDN 设成直连，就没事。

## 二、三层拆分（推荐）

### 第 1 层：核心链路（可移植，任何人都能用）

```
链接 → yt-dlp 下载 → ffmpeg 提音频 → whisper 转写 → 大模型整理 → 输出 .md
```

- 依赖：`python` + `ffmpeg` + `yt-dlp` + `openai-whisper` 或 `faster-whisper` + 一个模型 API Key
- 覆盖：B站 / 抖音 / YouTube / X / 微博 等主流平台
- **不依赖**：任何代理产品、任何系统设置、任何第三方二进制
- 转写要**自适应**：Apple Silicon 走 `mlx-whisper`，其它平台走 `faster-whisper`（CPU 也能跑，只是慢）

### 第 2 层：可选增强（按需，标注清楚限制）

| 模块 | 限制 | 建议 |
|---|---|---|
| 视频号支持 | 仅 macOS + 微信桌面端 + 需要装本地下载器与根证书 + 需要设系统代理 | **单独成一个可选目录**，README 明确写「不装也能用其它平台」 |
| 小红书支持 | 不依赖代理，但依赖页面结构的自写解析器，**站点改版就会失效** | 保留，并在文档里写清「失效了怎么改」（parser 位置、字段路径） |
| X 支持 | 只用公开接口，免登录；接口随时可能变 | 保留 + `yt-dlp` 兜底 |

### 第 3 层：个人化（不要进公开版，或替换实现）

| 现状 | 为什么不能给别人 | 建议替换成 |
|---|---|---|
| **助理侧接了微信渠道** | 整套体验（收链接、推图）都依赖它，但这是**你的账号/渠道绑定**，别人复制不了 | 文档里写成一节「前置条件：把你的 IM 渠道接进来」，并保证**不接渠道也能用**（手动跑命令、看输出目录） |
| 长图推送微信 | 绑你个人的 IM 通道 | **默认关闭**；改成「输出文件到当前目录并打印路径」 |
| 归档到个人资料库目录 | 私人目录结构 | 改成配置项 `OUTPUT_DIR`，默认 `./output` |
| 长图渲染器 | 本身可移植（纯 Python），但样式带你的品牌色 | 可保留，把颜色抽成配置 |
| 个人专属词表词条 | 含私人语境 | 只留方法说明 + 1~2 个脱敏示例 |
| 转写常驻服务 | 收益只有 ≈1s | 不进公开版 |

## 三、要让「一键安装」成立，还需要补什么

1. **依赖自检脚本**：`install.sh` / `install.ps1`
   —— 检查 python / ffmpeg / yt-dlp / whisper，缺什么就提示怎么装，不自动改用户系统。
2. **配置模板**：`config.example.json`（API Key、模型名、输出目录），
   首次运行若不存在就**生成模板并提示去填**，而不是报错。
3. **去掉绝对路径**：全部改成 `Path.home()` / 环境变量 / 相对项目根。
4. **不要把第三方程序本体打进仓库**：下载器、代理工具、证书都让用户自己获取，
   README 写清「在哪拿、放哪」。
5. **写清能力边界**（避免一装就被骂）：
   - 只处理**有口播的视频**，纯音乐/无声视频转出来是幻觉；
   - 平台接口随时会变，**失效是常态**，给了改的办法；
   - 不做去水印、不做批量爬取、不绕过付费内容。
6. **双格式兼容**：`SKILL.md`（Claude Code 技能）与 `AGENTS.md`（Codex 约定）各放一份，
   内容同源，避免两边规则漂移。
7. **写清输入来源**：本项目**只验证过**「手机端转发 → 复制链接」这一种链接形态。
   其它形态（桌面端复制、分享卡片、短链二次包装）没有验证，
   README 要如实写，别让用户以为「什么链接都能吃」。
8. **渠道接入算可选步骤**：把「接入自己的 IM 渠道」单独写成一段前置说明，
   并明确「**不接也能用**」——核心链路自己就能跑，只是没有推送这一环。

## 四、结论

- 想给别人用，**必须先砍掉三层外部依赖**：视频号下载器、微信推送、个人目录。
- 砍完之后，剩下的东西在任何机器上都能跑，也**不需要任何特定 VPN 产品**。
- 你的网络踩坑经验**不要删**，但要从「某产品的操作步骤」改写成
  「**原理 + 通用做法**」：比如「用了规则代理时，视频 CDN 要设直连」——
  这句话对任何人都成立，且不绑定任何产品。
