# 08 · 发布清单与汇总（放 GitHub 前先看这份）

> 一句话：**拆两个仓。** 私有仓存「完整的、带我个人配置的」实物；公开仓只放
> 「别人 clone 下来能跑」的骨架 + 方法论文档。**推送前逐条过第五节的自检，命中就不推。**

## 一、两个仓的分工

| | 私有仓（建议 private） | 公开仓（对外的骨架） |
|---|---|---|
| 目的 | 换机 / 备份 / 给自己留底 | 别人一键下载，在自己的 Codex / Claude Code 里用 |
| 内容 | 全部脚本 + 全部词表 + 全部文档 + 本地运行痕迹 | 核心链路脚本 + 方法论文档 + 脱敏示例 |
| 含个人信息 | 含（路径、渠道绑定） | **不含** |
| 第三方二进制 | 可留（体积大，也可不放） | **一律不放**，README 写清去哪拿 |
| 现在能不能推 | 能（只要不含凭据文件） | 还要补骨架（见第 5 节） |

## 四、这套东西真正值钱的三点（README 里要突出）

1. **一条命令端到端**：链接进去、长图出来。慢的从来不是程序，是「每完成一步都要重新决策一轮」。
2. **确定性纠错优先于模型纠错**：专有名词靠一张可维护的词表改，不指望模型「聪明」；
   现在覆盖 **10 个领域 394 条**，并且**两层都会真的改写**（英文自动归位、中文按变体精确改）。
3. **协作纪律**：助理只调度与汇报、重任务独立执行、失败两次止损、只发图不发大段文字。
   这套规矩比脚本更可复用。

## 六、公开仓还缺的骨架（推之前要补）

1. `install.sh`：自检 python / ffmpeg / yt-dlp / whisper，缺什么提示怎么装，**不擅自改系统**。
2. `config.example.json`：API Key、模型名、输出目录；首次运行不存在就生成模板并提示。
3. `SKILL.md` + `AGENTS.md` 双份（Claude Code / Codex 各一份，内容同源，防规则漂移）。
4. `.gitignore`：凭据、输出目录、缓存、二进制。
5. README 能力边界（避免一装就被骂）：
   - 只处理**有口播的视频**，纯音乐/无声视频转出来是幻觉；
   - 平台接口会变，**失效是常态**，文档里给「怎么改」；
   - 不做去水印、不批量爬、不碰付费内容；
   - **只验证过「手机端转发 → 复制链接」一种输入形态**，其它形态未验证，如实写。
