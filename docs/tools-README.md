# 自制脚本清单

分两部分：**一键成稿链路**（在工作区 `tools/` 下）与**通用小工具**（在 `~/.local/bin/`）。

## 一、一键成稿链路（`tools/`）

| 脚本 | 作用 | 备注 |
|---|---|---|
| `make_card.py` | ⚡**日常入口**：一条命令端到端 | 平台识别 → 解析 → 下载 → 转写 → 整理 → 归档 → 出图 → 推送 → 建索引；收尾打印 `@@CARD@@{json}` |
| `pipeline.py` | 解析 → 下载 → 提音频 → 转写 | 输出 `@@RESULT@@` JSON；含短链归一化与快速失败补丁 |
| `platforms.py` | 链接 → 平台识别 | 支持多 TLD 变体；已下线平台只用于回一句说明 |
| `format_doc.py` | 调大模型做结构化整理 | 产出「关键要点 + 完整文案」；专有名词提示由词表生成 |
| `fix_terms.py` | 专有名词纠错词表 + 巡检 | 单一维护点：热词偏置 / 确定性替换 / 提示兜底 |
| `xhs_reply.py` | 某社区平台专用解析 | 绕开过期适配器，自解析分享页 |
| `x_reply.py` | 短内容平台专用解析 | 走公开接口免登录，无直链时用 `yt-dlp` 兜底 |
| `sph_reply.py` | 只要文字稿（不要长图）时的入口 | 覆盖通用平台 |
| `whisper_server.py` | 转写常驻服务 | **默认不启用**（只省 ≈1s，不值维护成本） |
| `mcp_call.mjs` | 通过 MCP 调本地服务 | 排错时用它列工具、查任务状态 |
| `ima_upload.py` | 往知识库上传 | 依赖的连接器当前禁用 |
| `enqueue.py` / `queue_worker.py` / `sph_bot.py` / `sph_worker.py` | 早期队列 / 机器人方案 | **已停用**（会造成重复回复），保留仅作参考 |
| `wxcd/` | 第三方下载器本体与其配置 | 不建议公开分发 |

## 二、通用小工具（`~/.local/bin/`）

| 工具 | 作用 |
|---|---|
| `md2pic` | Markdown → 长图 PNG（封面卡片 / 要点徽章 / 分节序号） |
| `wx-send` | 把图片或文字推到微信 |
| `whisperd` | 转写常驻服务的状态与开关 |
| `all-sessions` | 列出近期有活动的任务窗口与最近几条发言 |
| `ai-rule` | 把「审批 / 提问档案」自动长成规则文件 |
| `jev-triage` | 回复长度分诊：判一条消息要答多长、要不要先反问 |
| `lark-bot-doctor` | 协作平台机器人一键诊断 |
| `lark-decrypt` | 协作平台内容解密 |
| `cx` | 模型通道切换 |
| `qq_chime` / `codex-notify-*` | 提醒音与通知路由 |

## 三、外部依赖

| 依赖 | 用途 | 是否必须 |
|---|---|---|
| macOS（Apple Silicon） | 转写依赖 Apple 神经引擎加速 | 必须 |
| `ffmpeg` / `ffprobe` | 提音频、看音轨 | 必须 |
| `mlx-whisper` | 本地转写 | 必须 |
| 大模型 API | 整理成结构化文案 | 必须 |
| 本地解析服务 | 取视频直链 | 必须（可用替代实现） |
| 一个本地 HTTP 代理（MITM） | 唯一需要代理的平台走这条 | 仅该平台需要 |
| `yt-dlp` | 个别平台的直链兜底 | 可选 |

## 四、环境约定

- 转写与整理**都在本机跑**，只有文字发到云端模型，音频不出本机。
- 所有临时视频 / 音频落在系统临时目录，跑完自动清理。
- 归档区与工作区分离：产出进 `资料库/`，脚本与运行目录留在工作区。
