# 00 · 总览与平台矩阵

## 两条并行链路（互不替换）

| 链路 | 入口 | 适用 | 依赖 |
|---|---|---|---|
| **跨平台版（v2，默认推荐）** | `tools/video2draft.py` | macOS / Windows / Linux | 仓库内 Python 依赖 + yt-dlp + ffmpeg + Chrome |
| Legacy 稳定版（保留） | `tools/make_card.py`、`tools/pipeline.py` | macOS 本机环境 | 本机解析服务、Node、wx-send 等本地组件 |

Legacy 只作为既有 macOS 环境的稳定版本保留，不在跨平台改造范围内；新环境请直接用 v2。

## v2 整体链路

```
   链接（命令行 / 上层渠道）
        ↓
   ① 平台识别（tools/platforms.py）
        ↓
   ② 适配器取媒体（tools/adapters/）
        ├─ 抖音 / B站 / YouTube → 仓库安装的 yt-dlp（python -m yt_dlp）
        ├─ 小红书              → 纯 Python 解析分享页 noteData
        ├─ X                   → 公开 syndication 接口，yt-dlp 兜底
        └─ 视频号（可选）       → 第三方解析服务，需自行配置
        ↓
   ③ ffmpeg 提音频（16k 单声道 wav）
        ↓
   ④ 本机离线转写（faster-whisper CPU；Apple 芯片可用 mlx 加速）
        ↓
   ⑤ 专有名词纠错（术语库，确定性替换 + 复读清理）
        ↓
   ⑥ 整理成稿（配置了 DeepSeek Key 则智能整理；没配则输出原始转写稿）
        ↓
   ⑦ 产出：<标题>.md ＋ <标题>.png ＋ <标题>.json
```

核心程序**只出 MD / PNG / JSON**，不做任何微信收发（推送由外层负责）。

## 平台支持矩阵（2026-09-20 复核）

| 平台 | 跨平台状态 | 取流方式 | 备注 |
|---|---|---|---|
| 抖音 | ✅ macOS 已实测通过（15s） | 解析服务直出解密直链 | 分享链一次归一化，无风控无二次跳转 |
| B站 | ✅ macOS 已实测通过（21s） | 公开 API + CDN 直链（自写 `bili_reply.py`） | 页面风控看 TLS 指纹，412 时绕开页面走 API；只下音轨 |
| YouTube | ✅ macOS 已实测通过（62s，`yt_reply.py` 只下音轨） | yt-dlp | 机房/VPN 出口可能触发机器人校验，可用浏览器 cookies 解决 |
| 小红书 | ✅ macOS 已实测通过（31s，`xhs_reply.py` 自解析新版页面） | 自写解析器 | 图文笔记无视频，会明确报错 |
| X / Twitter | ✅ macOS 已实测通过（31s） | 公开 syndication + yt-dlp 兜底 | 免登录公开接口 |
| 视频号 | ⚠️ **macOS 已验证 / Windows 未验证** | 第三方解析服务（可选） | 上游自称支持 Windows，但本项目未在 Windows 实机验证，故不标记支持 |
| 微博 / TikTok / 快手 | ❌ 不做 | — | 识别表保留域名只为提示，不进入下载转写 |

### 双系统 CI 实测（2026-09-20）

`GitHub Actions` 的 `macos-latest` 与 `windows-latest` 各跑一遍，**基础测试**与**离线全管线端到端**
（合成语音 → ffmpeg → faster-whisper → MD → PNG）两台机器都通过；Windows 上的 PNG 由 Chrome 无头渲染产出。
**但「真实 YouTube 链接」这一步在 CI 上被 YouTube 反爬拦截**（机房 IP：`Sign in to confirm you're not a bot`），
所以 Windows 目前只能算「基础与管线已实测」，**不能算整体已验证**。详见
[docs/11-跨平台重构与验收.md](11-跨平台重构与验收.md)。

### 六平台同晚实测与提速复盘（2026-09-20 晚）

当晚用真实链接把 六平台 全部端到端实测：抖音 15s / 视频号 16s / B站 21s / 小红书 31s /
X 31s / YouTube 62s（首测 220s，改为 yt-dlp 只下音轨后 3.5 倍提速）。
问题→原因→解法→定型链路，详见
[docs/13-六平台实战复盘与提速.md](13-六平台实战复盘与提速.md)。

## 交付形态

- `<标题>.md`：成品文案
- `<标题>.png`：排版长图（出图失败**不影响** MD 产出，只是少一张图）
- `<标题>.json`：结果 JSON（标题 / 作者 / 时长 / 字数 / 路径 / 各步骤状态）

## 目录与环境变量

| 变量 | 默认 | 作用 |
|---|---|---|
| `YJCG_OUTPUT_DIR` | `~/Video2Draft` | 输出目录（与代码目录彻底解耦） |
| `YJCG_TMP_DIR` | 系统临时目录 | 中间产物 |
| `YJCG_FFMPEG` | PATH 中的 ffmpeg | 音频提取 |
| `YJCG_CHROME` | 自动探测 | 出图用的无头浏览器 |
| `YJCG_WHISPER_MODEL` | `small` | tiny / base / small / medium / large |
| `YJCG_COOKIES_FROM_BROWSER` | 空 | 如 `chrome`，给 yt-dlp 带登录态 |
| `YJCG_COOKIE_FILE` | 空 | Netscape 格式 cookies 文件 |
| `YJCG_SPH_ENDPOINT` | 空 | 视频号第三方解析服务地址（不设=该能力关闭） |
| `DEEPSEEK_API_KEY` | 空 | 不设则输出原始转写稿 |

代码目录一律用 `Path(__file__).resolve().parent` 推导，不写死任何个人路径。
